# Magnet Mayhem

A fast browser arcade game built around one simple mechanic: **drag the magnet and pull the cores into it before time runs out.**

## Current build
- Playable HTML5 canvas game
- Mouse + touch / pointer controls
- Progressive levels
- Combo multiplier and score
- Moving hazards
- Particle effects and screen shake
- Pause / replay / next-level flow
- Responsive desktop + mobile layout

## Run
Open `index.html` in a browser, or deploy the repository with GitHub Pages.

## Controls
**Drag / hold** anywhere in the playfield to move the magnet. Pull every core into the magnet while avoiding hazards.
