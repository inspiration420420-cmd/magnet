# Magnet Mayhem — Build Roadmap

## Current systems
- 1,000-level progression
- Procedural fields, cores and moving hazards
- Combo scoring, stars, best scores and coins
- Time / Freeze / Shield / Overdrive power-ups
- Persistent Upgrade Lab
- Medals / achievements
- Daily challenge entry point
- Player statistics
- Touch, pointer and double-tap controls
- Keyboard shortcuts and fullscreen mode
- Installable PWA and offline cache
- Responsive neon presentation

## Next development passes
1. Expand boss levels into distinct mechanical encounters.
2. Turn daily challenge themes into gameplay modifiers and streak rewards.
3. Add more upgrade branches and unlockable magnet skins.
4. Add richer progression screens and end-of-run summaries.
5. Perform a browser/mobile compatibility and gameplay-balance pass.
