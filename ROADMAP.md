# Magnet Mayhem — Build Roadmap

## Current systems
- 1,000-level progression
- Procedural fields, cores and moving hazards
- Five rotating sector themes with active movement/hazard mutators
- Boss levels every 10 levels with escalating phase pressure
- Combo scoring, stars, best scores and coins
- Time / Freeze / Shield / Overdrive power-ups
- Persistent Upgrade Lab
- Medals / achievements and run statistics
- Daily challenge modifiers, replay-safe state and best scores
- Dedicated Level Select
- Touch, pointer and keyboard shortcuts
- Fullscreen, reduced-motion and visibility-pause support
- Installable PWA with versioned offline cache
- Responsive neon presentation

## Next development passes
1. Distinct bespoke boss encounters with phase-specific attacks.
2. Additional upgrade branches and unlockable magnet skins.
3. Richer progression screens and end-of-run summaries.
4. Browser/mobile compatibility and balance testing on physical devices.
